# 架构设计 · v0.2.1

main.py负责导入与阅读API；epub.py不解压到文件系统，限制ZIP条目与XML实体。library.py维护FTS5触发器、批注、版本进度；restore.py先验证整份备份再开启写事务。offline.js按账户缓存只读书库API，localStorage仅保存进度队列，sw.js缓存页面壳，不缓存API。

text_encoding.py在本机处理TXT：优先BOM与严格UTF-8，最多256KiB采样检测，再对全文件严格解码；对齐换行辅助识别无BOM Unicode。稀疏NUL字符占比不超过0.1%时移除并报告数量，稠密NUL与明显二进制拒绝。自动猜测有歧义时用户可指定编码；编码损坏不以替换符静默丢字。原文件不写回。

## 模块和边界

FastAPI + SQLite + 无构建原生Web UI。数据库外部调用不放入长写事务；默认Host/Origin校验、CSP和输入转义。

- EPUB提取正文及manifest内引用的PNG/JPEG/WebP栅格插图；图片独立画廊，不保留原始复杂排版/行内位置；不支持PDF。
- 离线前需点“保存整本离线副本”；离线支持已缓存正文和进度，批注/导入/书签修改需联网。
- 新阅读界面通过DOM Range二分定位分页起点，按章节与正文字符比例同步；字体/窗口变化重排到包含原字符的页。旧版滚动比例读入新模式时可能位置变化；字段迁移到整数字符偏移仍待实现。
- 同步面向同一后端的多个客户端，不是已部署的跨设备云服务；没有原生桌面安装器。
- 默认回环访问，访客local是本机共享空间；账户可隔离内容，但不是公网多租户安全承诺。Cookie为本机HTTP设置，公网需TLS、安全Cookie、关闭访客、限流与部署审计。

reading.js以CSS columns显示单章，每屏一页，不裁掉或复制正文；阅读设置与管理操作在对话框，目录为可收起抽屉，宽度变化重新测量。LAN入口仅用户手动运行app.lan，绑定明确的RFC1918 IPv4，Host校验和原有同源请求限制保留；该模式禁用数据API访客访问。没有自动改防火墙、公网部署或真实手机连接验证。

## 栅格插图

illustrations.py以Pillow验证真实格式、单帧、像素/边长/字节限额，重建像素PNG移除EXIF/profile/text元数据。图片与book/chapters/FTS在同一SQLite事务写入；images BLOB表有book外键。列表/PNG端点均验证书主及未删除状态，PNG响应private/no-store；归档原始HTML/SVG不提供给浏览器。

epub.py规范化url解码后的归档相对路径，只允许未越出ZIP根的manifest资源；拒绝ZIP重复名/过量压缩等，超限栅格拒绝整本导入，外部/data/SVG等跳过并返回不含源地址的提示。单张原始及PNG≤2MiB、边≤4096、像素≤800万，200张/32MiB全书限额。长正文按12000字符拆分，插图归原章首节；不是行内版式。既有XML字节DOCTYPE/ENTITY检查不等于全面XML沙箱，其他编码等扩展防护仍需独立审计。

含图片digest加入章节/顺序/alt/PNG SHA256；无图片保持历史文本digest。backup v1增加base64 illustrations；恢复先实际解码所有图片/验证位置和尺寸/整份200张32MiB总限额，再单事务写所有书籍。旧无图备份兼容，旧客户端丢弃新增字段的兼容损失不保证。书库导出超过恢复总限额时需分批迁移。

illustrations.js独立于正文DOM，切章/返回清空图片节点，用代次检查丢弃陈旧目录响应。图片仅联网，IndexedDB整书离线副本仍只有正文；SW v10缓存新增脚本而不缓存图片API。浏览器反复变更尺寸仍有页首量化回退，是既有字符比例定位限制，不声称图片增加解决了精确锚点。
