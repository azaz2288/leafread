# 运行与恢复

使用README中的本机启动命令。访问 http://127.0.0.1:8767 。单进程运行，避免多个进程争抢本机后台队列。

## 数据备份

停止服务后备份整个APP_DATA_DIR（默认data/），包含app.db、媒体/处理资源和队列输入文件。运行时直接拷贝SQLite单文件可能丢失WAL事务，必须先停机或使用SQLite backup API。恢复时停机，将完整备份放入数据目录再启动。书库/知识库的页面JSON备份只覆盖页面说明的内容，不包含账户密码、会话或原始媒体。

日志可由uvicorn输出收集；异常队列在页面显示失败原因并可重试。监控 /openapi.json 和进程存活，不把上传数据发到外部监控。

## 本机部署

无需外部数据库、CDN或云账号。三个Web项目可使用仓库Dockerfile和compose.yaml；端口只发布在127.0.0.1，容器内使用0.0.0.0以接收宿主转发。不要把本机访客模式直接发布公网。Docker配置仅静态检查，本机未安装Docker运行时。

公网服务需要独立设计TLS、可信反向代理、Secure Cookie、禁用访客、注册和上传限流、平台审核、存储配额与备份恢复演练。当前账户用于本机内容隔离，不代表上述生产条件已完成。

## 大书导入

默认单本128MiB；启动前设置LEAFREAD_MAX_UPLOAD_MIB（1–1024）。页面从/api/config读取当前限额并显示上传进度。TXT正文按12000字符分章，阅读时只请求当前章；不是把整本书送到DOM。导入阶段仍需解码与构建FTS索引，会暂时占用与书大小相关的内存。EPUB解包总量256MiB、单项128MiB、最多20000条目，并保留路径、实体与压缩比保护。书库备份恢复上限256MiB/1.5亿字符。

## 手机阅读

手机浏览器支持分页、左右滑动、目录抽屉、夜读和设置。手机的127.0.0.1指手机自己；要访问电脑书库，先在电脑阅读器注册账户并导入到该账户。

在仓库运行 `powershell -ExecutionPolicy Bypass -File tools/start-phone.ps1`，选择与手机同一Wi-Fi的电脑IPv4。也可运行 `python -m app.lan --host 192.168.1.50 --port 8777`，将示例地址换成电脑真实私网地址。手机打开启动时显示的地址，用同一账户登录。默认应用不会自行开启共享；脚本不修改防火墙，Windows询问访问时仅在可信家庭私网允许。保持电脑运行，不设置路由器公网转发。

局域网入口仅HTTP，适用于可信网络，浏览器通常不会提供Service Worker、离线安装等需HTTPS的能力。桌面localhost离线缓存仍有效；手机离线/PWA需要单独配置可信HTTPS。当前只验证手机尺寸与模拟LAN请求，真实手机和Wi-Fi联通需要在用户设备上验证。
